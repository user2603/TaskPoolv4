# TaskPoolv4

Snapshot of the bench task pool maintained by the dev leads.

- `tasks/<task id>/` holds each task scaffold (spec.md, build.md, checks.md).
- `export/tasks_index.csv` is the CI-generated index of every task with
  its file count and total byte footprint. Regenerated on every merge.
- The registry of record for reporting lives in Notion (Task Registry).
